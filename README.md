# COMP 590 Assignment 4: Build and Deploy to the Quest

## Video
https://youtu.be/ImUXyjvAhQU

## What I made
A mixed reality scene for the Meta Quest 3. Passthrough shows the real room
through the headset's cameras, and four colored cubes float in front of the
player. The cubes can be grabbed and thrown with either the controllers or
hand tracking.

## How it was built
- Unity 6000.5.9f1 (Universal Render Pipeline), Android build target
- Meta XR SDK with OpenXR (Meta XR feature group)
- Meta Building Blocks: Camera Rig, Passthrough, Grab Interaction
